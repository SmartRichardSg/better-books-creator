4. Standard Better Books structure

Use this framework as appropriate to the manuscript. If a section already exists, keep it and do not duplicate it.

  1. Cover — use the approved uploaded cover unchanged.
  2. Author's Note — include only if supplied/approved; never invent one.
  3. Disclaimer — standard page, once only.
  4. Copyright — use the commercial or free-companion wording selected by book type, once only.
  5. Clickable Table of Contents — proper Kindle navigation.
  6. Introduction and main manuscript — preserve approved wording and chapter order.
  7. Challenges, action plans and worksheets — retain if supplied; format for readability.
  8. Conclusion / epilogue — preserve the approved ending.
  9. Discover More from Smart Richard — standard final page with clickable links and the QR code below.

Manuscript rule: the pasted manuscript ends at the book's final full stop. Do not put copyright, disclaimer, QR code, resource links or standard closing page inside the manuscript; the framework adds these separately. Detect and remove accidental duplicates without deleting real book content.

Official Better Books QR code

Scans to the official Better Books website. Use this QR image on the final “Discover More” page and include a clickable text link beside it. Keep it black on white, at a readable size, with clear white space around it. Test the embedded QR code before delivery.

Standard links: Better Books website — https://smartrichardsg.github.io/BETTER-BOOKS-by-Smart-Richard/ · Better System App — https://smartrichardsg.github.io/-Better-System-App-/ · Better Life App — https://smartrichardsg.github.io/-Better-System-App-/better-life.html · Feedback — SmartRichardsg@gmail.com

Standard closing-page rule: promote the three Better Books titles (Better Brain, Better Memory, Better Life) and only the two companion web apps (Better System App and Better Life App). Include each book's cover, title, subtitle and short description. Include the supplied screenshots for both apps, plus these truthful app notes: free to use, no advertisements, data stored locally on the user's device, tested on iPhone, and as web apps they should also work on Android phones. Do not introduce unrelated products or apps. Required reusable assets: better-brain-cover.png, better-memory-cover.png, the current book cover, better-system-app-screenshot.jpg and better-life-app-screenshot.jpg. If an asset is not attached to the production brief, ask for it rather than inventing a screenshot or cover.
