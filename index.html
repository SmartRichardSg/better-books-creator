4. Standard Better Books structure

Use this framework as appropriate to the manuscript. If a section already exists, keep it and do not duplicate it.

  1. Cover using the uploaded image unchanged
  2. Copyright page and disclaimer (front only)
  3. Author's note / introduction
  4. Clickable table of contents
  5. Chapters in the manuscript's existing order
  6. Challenge, action plan, worksheets or reflection record when relevant
  7. Closing chapter / epilogue, if supplied
  8. “Discover More from Smart Richard” resource page
